# 产品概览

## 产品定位

本项目不是 ERP、MES、WMS 或 OA 的替代品，而是建立在企业现有系统之上的经营分析与轻量行动层。目标用户是老板、厂长和经营管理负责人。

## 核心价值

1. 将订单、物料、采购、生产、成本和应收数据串联为经营风险。
2. 将“看报表”升级为“问问题—看证据—做决策”。
3. 将大模型限制在理解、编排和表达范围内，业务数字由代码计算。
4. 将分析结论通过人工确认发送给部门负责人，并记录回执和反馈。

## 主要模块

- 经营驾驶舱：高风险订单、风险金额、缺料、价格异常和高风险应收。
- 订单风险：风险评分、风险构成、生产进度和全生命周期。
- 缺料与预警：物料齐套、短缺数量、需求日期和关联采购。
- 供应商分析：价格、交付、质量、响应和稳定性评价。
- 成本与报价：完整成本、毛利、报价与历史参考。
- 情景模拟：价格、供应商、批量、锁价、汇率、停供和交期变化。
- 应收与报告：账龄风险、日报、周报和月报。
- AI 与行动：经营问数、多步骤决策、风险任务和飞书闭环。

## 角色设计

- 老板/厂长：查看全局、经营问数、发起部门行动。
- 部门负责人：接收事项、确认已收到、反馈需要协调。
- Web 演示角色：用于展示菜单差异，不等同于生产身份认证。
