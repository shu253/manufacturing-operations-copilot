# 离散制造业务流程

项目采用面向订单的离散制造模型，适用于设备、机械、零部件和装配型企业。

```text
客户需求
→ 销售订单
→ 产品与BOM
→ 生产订单
→ 物料需求展开
→ 库存与采购分配
→ 供应商交付
→ 生产执行与质量
→ 发货
→ 开票
→ 应收与回款
```

## 风险识别过程

系统以销售订单为主线，按明确业务编号关联生产订单、物料需求、采购订单和成本数据：

1. 根据 BOM、生产数量和损耗计算物料需求。
2. 汇总领料、库存分配和需求日前可到货采购，计算行齐套率和数量齐套率。
3. 比较预计到货日、物料需求日和订单交期，识别采购迟交。
4. 比较理论生产进度和实际进度，识别生产落后。
5. 汇总缺料、采购、生产、质量和临期规则，形成订单风险分。
6. 结合完整成本、毛利和应收，生成经营动作建议。

时间先后本身不被当作已确认因果关系；跨环节分析必须能够通过相同业务编号建立连接。
