# Dify 工作流

## 单步骤经营问数

```text
用户问题
→ 问题分类
→ 参数提取
→ 参数完整性判断
→ 调用受控工具
→ 工具结果检查
→ 大模型组织答案
→ 数字校验
→ 返回
```

支持订单概况、订单风险、缺料、采购迟交、生产进度、供应商、成本、报价、情景模拟、应收、经营报告、制度问答和无法识别等意图。

## 多步骤决策

“为什么是高风险订单，应该怎么处理”会依次调用：

```text
订单风险
→ 订单齐套
→ 采购迟交
→ 生产进度
→ 订单成本
→ 证据合并与裁剪
→ 决策表达
```

## 参数约束

- 不猜测订单、物料、供应商、客户、日期、数量和比例。
- 参数缺失时追问用户。
- 大模型不能指定数据库路径、表名或任意 URL。
- Dify 自定义工具使用 Bearer Token 调用 FastAPI 白名单路径。
- 网络错误、超时、429 和常见 5xx 执行有限重试，仍失败则安全返回。

可导入工具定义见 `dify/openapi-tools.yaml`，提示词和代码节点位于 `dify/multi-step-decision/`。
