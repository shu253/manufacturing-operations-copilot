# 部署与产品化边界

## 本地演示

本地演示由 FastAPI、React 静态构建、SQLite、可选 Dify Cloud 和飞书长连接组成。关闭电脑或相关进程后，飞书机器人和临时公网通道会停止。

## 客户部署建议

```text
客户需求与数据盘点
→ ERP/MES/财务字段映射
→ 数据适配器与只读账号
→ 业务规则和口径确认
→ 私有测试环境
→ Dify与模型配置
→ 企业身份和飞书应用
→ UAT与数字核验
→ 生产发布
→ 监控、备份和运营
```

## 生产化待补能力

- 云服务器或客户内网常驻部署，不依赖个人电脑。
- PostgreSQL/客户数据仓库替换 Demo SQLite。
- 企业 SSO、后端 RBAC、组织和数据权限。
- 容器化、CI/CD、HTTPS和正式域名。
- 集中密钥管理、日志脱敏和密钥轮换。
- 监控告警、链路追踪、备份恢复和容量评估。
- 客户专属公式、数据质量校验和验收基线。

公开仓库不会包含任何可直接访问真实飞书、Dify或客户系统的密钥。
